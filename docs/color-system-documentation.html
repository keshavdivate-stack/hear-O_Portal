Color Guide

A simple guide to the colors used, and what each one means.

1. Primary & Secondary Colors

These are the main colors used across the app for buttons, links, and highlights.

Primary Color — Blue

Blue is our main color. It is used for links, buttons, and important actions.

Blue#2AA9E0

Secondary Colors

These extra colors are used for special tags and labels, mostly in the clinic admin screens.

Button Blue#2563EB

Neutral Colors

Grays are used for backgrounds, borders, and regular text that isn't a color status.

2. Semantic Colors

Semantic colors have a fixed meaning everywhere in the app. Green always means "good," orange/amber always means "warning," maroon always means "error," red always means "critical/priority," and so on. Each color has three versions: a solid color (for icons and dots), a text color (easier to read), and a light background (for badges).

Green — Good / Success

Green means everything is fine: data is complete, a task is done, or the answer is "Yes."

Green#3FBE84
Green Text#15803D
Green Background#EAFBF3

Orange / Amber — Warning

Orange and amber mean something needs attention: data is low, a dose was missed, or the answer is "No."

Orange#F2994A
Orange Text#C25E00
Orange Background#FEEDDC
Amber#F59E0B
Amber Text#B45309
Amber Background#FEF3E1

Maroon — Error

Maroon means something is wrong: a system error, a failed action, or invalid input. It's a deep, muted red — distinct from Priority Red and from the Orange/Amber warning tones — so an error never gets mistaken for a critical patient or a simple warning.

Maroon#9F1C3B
Maroon Text#7A0F2B
Maroon Background#FCE8EC

Red — Priority / Critical

Red is reserved for patient priority: a critical alert or a high-priority patient. It is not used for system errors.

Red#F16C6C
Red Text#D92D20
Red Background#FDEDED

Yellow — Medium Caution

Yellow sits between orange and gray. It marks things that are medium priority — not urgent, but not fine either.

Yellow#D9A404
Yellow Text#7A5F00
Yellow Background#FEF8DC

Gray — Disabled / Not Available

Gray means something is turned off, not filled in, or not clickable.

Disabled Border#E7EAEE
Disabled Text#8D929A
Disabled Input Text#9AA5B1

3. Badges & Status Pills

Badges and status pills are the small rounded labels that show a patient's or task's status at a glance. They use a light background color with matching darker text from the semantic colors above.

Active / Completed / Healthy Pending / In Progress Critical / Priority Error Medium Priority Low Priority / Archived Escalated
ColorStatusWhat it means
Active / Completed / HealthyGreen background, green text. Everything is good.
Pending / In ProgressOrange-tinted background, orange text. Waiting or needs action.
Critical / PriorityRed background, red text. A high-priority or critical patient. Reserved for priority — not used for errors.
ErrorMaroon background, maroon text. A system error or failed action.
Medium PriorityYellow background, yellow text. Somewhat important.
Low Priority / ArchivedLight gray background, gray text. Not urgent.
EscalatedRed background, red text. Sent to a higher level — treated as urgent, same as Critical/Priority.
Quick rule of thumb: green = good, orange/amber = warning, maroon = error, red = priority/critical, yellow = medium, gray = low or inactive.
